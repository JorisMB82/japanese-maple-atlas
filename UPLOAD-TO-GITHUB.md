# Upload this release to GitHub

1. Download and unzip the release package.
2. Open the unzipped `japanese-maple-atlas-release-0.1` folder.
3. In the GitHub repository, choose **Add file → Upload files**.
4. Drag every file and folder from inside the release folder into the upload area. Do not upload the ZIP itself.
5. Use commit message: `Release 0.1: establish Atlas MVP foundation`
6. Commit directly to `main`.

After the upload, connect the repository to Vercel using the Next.js preset and default build settings.
