## 1. Requested permission scope

For the exact selected photographs, request written permission for the Japanese Maple Atlas to:

1. reproduce the photograph publicly in a non-paywalled cultivar reference;
2. preserve the supplied full-resolution original in the governed repository;
3. crop, resize, colour-manage and generate deterministic JPEG derivatives;
4. display the derivatives in the Atlas application and static release artefacts;
5. retain creator, rights-holder, source item and licence/permission records;
6. state an accession or specimen mapping publicly when JCRA confirms it;
7. remove precise GPS, personal and nonessential EXIF metadata from public derivatives;
8. continue displaying the item in future Atlas releases under the agreed terms.

Request the full-resolution original rather than a webpage thumbnail and ask JCRA to specify any attribution wording, licence, fee, duration, territory, platform, takedown or modification conditions.

## 2. Identity and mapping questions

For every selected item, ask JCRA to confirm:

- the exact photographed cultivar name and source spelling;
- whether the photograph is tied to a living accession or labelled specimen;
- the accession number and whether the Atlas may publish that mapping;
- whether one frame contains multiple taxa or does not isolate the named cultivar;
- whether the name reflects a current verified accession, a received-as name, a historical label or a photographer annotation;
- any known correction, replacement, deaccession or identity uncertainty.

The Atlas will use `documented` identity only when the supplied record supports it. Otherwise the public item will remain `source-asserted` with conspicuous qualification.

## 6. Suggested request text

> The Japanese Maple Atlas is a public, evidence-oriented cultivar reference project. We request permission to reproduce the photographs identified in the attached selection schedule, preserve the supplied full-resolution originals in our governed source repository, and create cropped/resized deterministic web derivatives for cultivar galleries. Public display will include item-level creator, source, rights and identity-confidence disclosures. We will not claim that the Atlas independently authenticated a clone unless JCRA supplies a documented accession or specimen mapping. Please confirm the exact permitted uses, required attribution, rights holder, full-resolution delivery method, any fee or conditions, and whether the selected photographs may be publicly mapped to the listed accessions. Precise GPS and nonessential personal EXIF will be removed from public derivatives while the governed source bytes and integrity hashes are preserved.

## 7. Acceptance boundary

A response is usable only when it identifies the exact items and grants the needed preservation, derivative and display rights. General website visibility, an attribution line, a verbal indication, or permission for a thumbnail alone is insufficient.

After a valid response:

1. preserve the permission record;
2. acquire the exact supplied originals;
3. calculate source SHA-256;
4. generate and inspect deterministic derivatives;
5. record derivative SHA-256 values;
6. create item-level sidecars with the correct identity confidence;
7. run the full media and repository validation chain;
8. submit the assets in a separate protected media PR.
