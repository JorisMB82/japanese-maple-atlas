# ROADMAP-001 — Development Roadmap (Post Sprint 6)

**Version:** 1.0  
**Status:** Authoritative  
**Effective date:** 2026-07-25

## Working principles

- Use `main` as the production source of truth unless another branch is specified.
- Work directly against the existing architecture.
- Prefer incremental improvements over rewrites.
- Produce production-ready code only.
- Repository integrity comes before UI enhancements.
- Finish every sprint with validation, build verification, documentation, commit message and merge instructions.

## Roadmap

- Sprint 7 — Editorial workflow and contributor pipeline
- Sprint 8 — Advanced search and semantic filtering
- Sprint 9 — Knowledge graph and cultivar relationships
- Sprint 9.5 — Testing and Quality Infrastructure
- Sprint 10 — Interactive Atlas explorer
- Sprint 11 — Media pipeline and IIIF readiness
- Sprint 12 — Repository-aware AI assistant
- Sprint 13 — Public API and SDKs
- Sprint 14 — Performance optimisation
- Sprint 15 — Release Candidate and production audit
- Version 1.0 — Production release

## Sprint execution workflow

1. Inspect repository
2. Implement
3. Validate
4. Run production build
5. Update documentation
6. Provide changed files, tests, commit message and merge instructions
7. Stop when the sprint is review-ready
