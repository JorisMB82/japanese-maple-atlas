## 1. Scope and boundary

This proposal converts programme slots 011–025 into a balanced first Catalogue cohort while preserving RC-001 through RC-010 as Reference Standards. It does not create Catalogue JSON, stable `CUL-######` identities, media approvals, schema changes or publication authority.

The preliminary duplicate review compared each proposal against the ten existing Reference Standards:

- RC-001 ‘Bloodgood’;
- RC-002 ‘Seiryu’;
- RC-003 ‘Sango-kaku’;
- RC-004 ‘Crimson Queen’;
- RC-005 *Acer shirasawanum* ‘Aureum’;
- RC-006 ‘Osakazuki’;
- RC-007 ‘Butterfly’;
- RC-008 ‘Shishi-gashira’;
- RC-009 ‘Katsura’;
- RC-010 ‘Mikawa-yatsubusa’.

No proposed cultivar is an exact duplicate of those records. Several are intentionally close comparators; those relationships are disclosed rather than treated as duplication.

## 3. Batch design

### C-001 — slots 011–015

1. ‘Orange Dream’ — yellow seasonal palmatum shrub;
2. ‘Koto-no-ito’ — green linearilobum;
3. ‘Inaba-shidare’ — red cascading dissectum;
4. ‘Beni-kawa’ — coral winter stems;
5. ‘Trompenburg’ — upright/spreading recurved-lobe purple cultivar.

This is the lowest-risk and highest-delivery-confidence batch. It contains five accepted names with strong institutional profile availability, high media feasibility and deliberately different product roles.

### C-002 — slots 016–020

1. ‘Autumn Moon’ — *A. shirasawanum*, yellow/orange larger shrub or tree;
2. ‘Waterfall’ — green cascading dissectum;
3. ‘Aoyagi’ — green bark and larger scale;
4. ‘Shin-deshōjō’ — compact spring-red interest;
5. ‘Red Dragon’ — compact red cascading dissectum.

This batch introduces the first targeted taxon/synonym review while retaining four high-confidence *A. palmatum* profiles.

### C-003 — slots 021–025

1. ‘Tamukeyama’ — red cascading cultivar with a synonym issue;
2. ‘Orangeola’ — orange seasonal dissectum;
3. ‘Higasa-yama’ — variegated collector cultivar with spelling variation;
4. ‘Arakawa’ — rough-bark collector cultivar with accepted-name/alias work;
5. ‘Red Pygmy’ — compact red linearilobum.

This is the collector-oriented batch. It contains more targeted review but no cultivar presently assessed HIGH risk.
