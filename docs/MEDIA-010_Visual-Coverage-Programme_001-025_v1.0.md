## 1. Purpose

This programme converts the Atlas media stream from a Reference-Standard-only sequence into a two-speed visual delivery programme.

The governing release rule is:

- Reference Standards retain full G5 requirements and may require multiple subjects or stronger specimen evidence;
- an ordinary Catalogue Profile resolves its visual state through one approved, rights-compliant primary visual or an explicit governed visual gap;
- additional seasonal, diagnostic and historical views remain valuable backlog enhancements rather than universal Catalogue release blockers.

Legal, provenance, privacy and identity safeguards do not change with publication class.

## 2. Public visual-state vocabulary

Every identity must resolve to exactly one public-facing state:

1. `primary visual approved` — approved source, rights, identity treatment, sidecar and derivative lineage are complete;
2. `visual candidate under review` — at least one specific item is being assessed, but C2/G5 has not passed;
3. `governed visual gap` — a reviewed and approved gap record exists; no generic cultivar substitute is shown;
4. `non-evidentiary illustration` — an approved Atlas illustration is displayed with the required synthetic/non-evidentiary disclosure.

Specimen identity is recorded separately as:

- `documented` — accession, determination or comparable institutional chain supports the depicted specimen;
- `asserted` — a named garden, nursery, contributor or file assertion is the available basis;
- `uncertain` — the cultivar attribution has a material unresolved ambiguity;
- `not applicable` — used only for non-evidentiary illustrations or non-specimen graphics.

A visual-state label never upgrades specimen identity.

## 6. Post-assignment feasibility review

For each proposed Catalogue assignment, media returns before owner approval:

- at least two candidate discovery routes where practical;
- item-level licence or permission posture;
- specimen-identity posture;
- likely primary subject;
- technical/source-preservation feasibility;
- estimated approval probability;
- likely governed-gap probability;
- expected external-permission latency;
- recommendation: `media-feasible`, `media-feasible with qualified identity`, or `likely governed gap`.

Media feasibility informs assignment but does not decide cultivar identity or programme selection.

1. Complete RC-010 candidate selection and permission/original request.

## 8. Completion rule

This programme is complete as a planning object when all five tranches have an explicit operating state, but visual completeness is measured only by approved primary assets or approved governed gaps. Candidate discovery alone is not visual completion.
