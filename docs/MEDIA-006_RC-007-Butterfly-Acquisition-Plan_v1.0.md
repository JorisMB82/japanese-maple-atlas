## Required coverage

1. whole-plant spring or early-summer habit;
2. branch-level view showing variegation distribution among shoots;
3. scaled leaf detail with upper/lower surfaces, petiole and irregular margin pattern;
4. spring pink tinting;
5. summer persistent cream-white margins;
6. autumn view from the same accession where possible;
7. any non-variegated shoot documented separately.

Avoid overexposure that erases white/green boundaries. One variegated leaf is not cultivar-identity evidence. The package must distinguish ‘Butterfly’ from ‘White Butterfly’ and other marginal variegates.
