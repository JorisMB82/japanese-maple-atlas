# Sprint 5 — Media System

## Status

Implemented.

## Capability shipped

Sprint 5 makes media a first-class Atlas repository object.

The release includes:

- five standardized SVG identity plates;
- one governed media object per pilot cultivar;
- media schema;
- media hydration in the repository service;
- primary-media selection;
- media integrity checks;
- visual identity plates on cultivar cards;
- profile hero imagery;
- full media metadata panel;
- standardized imagery in comparison;
- media index page;
- explicit separation between illustration and evidence;
- MEDIA-001 pilot media standard.

## Visual approach

The identity plates are procedural editorial illustrations designed to make
the interface usable before licensed or original photography is available.

They provide:

- consistent canvas;
- consistent framing;
- consistent annotation;
- low file size;
- no third-party image licence cost;
- immediate replaceability.

They do not claim diagnostic fidelity and are labelled accordingly.

## Review gate

Before public beta:

1. compare each identity plate against the canonical RC record;
2. refine habit, branching, leaf form, and colour;
3. decide the long-term content licence;
4. add real photographs where rights and authenticity are documented;
5. retain a visible distinction between illustration and evidence.
