# Catalogue media sidecars

Approved Visual-First Catalogue media sidecars use:

`CUL-######.media.json`

Each sidecar validates against `atlas-repository/schemas/catalogue-media.schema.json` and may contain one to five approved lawful photographic items using stable `MED-CUL-######-###` identifiers.

Normal galleries contain:

- one `habit-primary` item;
- one `foliage-detail` item;
- one `seasonal-diagnostic` item;
- up to two complementary items.

Rights-unresolved candidates do not belong in this directory. They remain in governed candidate registers until a lawful reuse basis is documented.

The directory intentionally contains no real sidecar at initial implementation. Existing C-001 governed gaps remain authoritative until the media stream returns approved packages.
