# Release 0.2 — Usable Product Sprint

## Objective
Turn the technical foundation into a coherent pilot experience that can be deployed and shown to users.

## Shipped capabilities
- Reworked Atlas navigation and product identity
- Searchable, filterable, sortable cultivar directory
- Redesigned cultivar cards and profile pages
- Seasonal-expression timeline
- Diagnostic-trait presentation
- Structured assertion/evidence component
- Enhanced comparison workspace with swap and differences-only mode
- Source register
- About/product-vision page
- Repository statistics and data-status communication
- Responsive layouts across the full application

## Data status
All cultivar statements remain provisional pilot data. Release 0.2 improves the product layer; it does not claim to replace the frozen Reference Standards.

## Next sprint
Canonical normalization of RC-001 through RC-005, followed by Vercel deployment and pilot testing.
